# 📖 About The Project

ECCAT One is a full-stack academic management system built exclusively for:

<b>Egyptian Chinese College for Applied Technology (ECCAT)</b>

The platform centralizes academic operations into one secure digital ecosystem designed for:

* 🎓 Students
* 👨‍🏫 Doctors
* 🏢 Department Heads
* 🛠 Administrators

This project follows a structured, production-level development roadmap with scalability and clean architecture in mind.

---

# 🏗 System Architecture

```
eccat-one/
│
├── backend/
├── frontend-web/
├── frontend-mobile/ (later phase)
└── docs/
```

The system is designed using clean separation of concerns and modular architecture.

# 🛣 Development Roadmap

The system is being built in controlled engineering phases.

---

## 🔐 Phase 1 — Authentication & Access Control

### 🎯 Goal

Build secure identity management.

### Backend

* User Model
* Registration Code System (Admin Controlled)
* Login / Logout
* JWT Access Tokens
* Refresh Token Rotation
* Role Middleware
* Protected Routes

### Frontend

* ECCAT Branded Landing Page
* Login Page
* Activate Account Page
* Protected Layout
* Role-Based Dashboards

### ✔ Completion Criteria

* Admin-only registration control
* Secure JWT authentication
* Role-based redirection
* Protected routes fully enforced

# 🌳 Git Workflow

```

```

## Feature Branch Naming

```

feature/auth-frontend
feature/landing-page
feature/dashboard-student
```

## Rules

* ❌ No direct push to main
* ✅ All work from develop
* ✅ Pull Request required
* ✅ Code review before merge
* ✅ Clear commit messages
